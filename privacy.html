プライバシーポリシー

「YouTube記録」（以下、本アプリ）が、Googleアカウントの許可によって受け取る情報の扱いを定めます。

受け取る情報

許可をいただいたYouTubeチャンネルについて、次の情報を読み取ります。書き込み・投稿・削除は行いません。

  • チャンネル名、登録者数、動画の一覧（タイトル・公開日・長さ・公開状態）
  • YouTubeアナリティクスの数字（再生数、総再生時間、平均視聴時間、登録者の増減、推定収益、インプレッション、クリック率など）

使い道

読み取った数字は、チャンネルの持ち主ご本人のGoogleスプレッドシートに書き込むためだけに使います。広告、販売、第三者への提供には使いません。

保存

数字そのものは、ご本人のスプレッドシートにだけ保存されます。本アプリの運営側が保存するのは、毎朝の読み取りに必要な許可の情報（更新用トークン）、チャンネル名、取り込みの成否と日時だけです。

許可の取り消し

Googleアカウントの「サードパーティ製のアプリとサービス」から本アプリへのアクセスを削除すると、いつでも読み取りを止められます。ご利用を終えたときは、運営側で預かっている許可の情報も削除します。

Google API サービスのユーザーデータに関するポリシー

本アプリによるGoogle APIから受け取った情報の利用は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に従います。
